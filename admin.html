3 bước đưa lên web thật

  1. Tải ảnh mới: bấm "Tải ảnh mới" — chỉ tải ảnh của sản phẩm mới thêm/vừa đổi ảnh, sản phẩm cũ không đổi ảnh thì khỏi cần tải lại.
  2. Đưa ảnh lên GitHub: kéo các ảnh vừa tải vào thư mục images/products/ trong repo.
  3. Dán code: copy đoạn code bên dưới (đã gồm chữ const products=[...]), THAY THẾ TOÀN BỘ khối products cũ trong index.html, rồi lưu lên GitHub. Vercel sẽ tự build lại.
